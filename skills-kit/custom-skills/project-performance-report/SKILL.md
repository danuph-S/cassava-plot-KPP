# รายงานผลการดำเนินงานโครงการ

## ขั้นตอน

1. **รวบรวมข้อมูลจากสิ่งที่ผู้ใช้ให้มา** (ไฟล์ Excel/CSV, เอกสารโครงการ, รูปภาพกิจกรรม, บันทึก) อ่านทั้งหมดก่อนเขียน
2. **ถามข้อมูลที่ขาดในครั้งเดียว**: ชื่อโครงการ, หน่วยงานรับผิดชอบ, ช่วงเวลารายงาน, รูปแบบไฟล์ที่ต้องการ, แบบฟอร์มของหน่วยงาน (ถ้ามีให้ยึดแบบฟอร์มนั้น)
3. **คำนวณตัวเลขด้วยโค้ด** (pandas/Excel) ไม่คิดในหัว: ร้อยละความสำเร็จ KPI = ผลจริง ÷ เป้าหมาย × 100, ร้อยละการเบิกจ่าย = เบิกจ่ายจริง ÷ งบที่ได้รับ × 100
4. **เขียนรายงานตามโครงร่างด้านล่าง** แล้วสร้างไฟล์ด้วย skill `docx` / `pptx` / `xlsx` (ถ้าเป็นหนังสือนำส่ง ใช้ skill `thai-gov-letter`)
5. **สรุปให้ผู้ใช้ในแชต** 3–5 บรรทัด: ผลสำเร็จหลัก, KPI ที่ไม่ถึงเป้า, ประเด็นที่ต้องตัดสินใจ

## โครงร่างรายงาน

1. **ข้อมูลทั่วไปของโครงการ** — ชื่อโครงการ, หน่วยงาน, ผู้รับผิดชอบ, ความสอดคล้องกับยุทธศาสตร์/แผน (ถ้าผู้ใช้ระบุ), ระยะเวลา, งบประมาณ, พื้นที่ดำเนินการ, กลุ่มเป้าหมาย
2. **วัตถุประสงค์และเป้าหมาย** — เชิงปริมาณ และเชิงคุณภาพ
3. **ผลการดำเนินงาน**
   - ตารางกิจกรรม: กิจกรรม | แผน | ผล | สถานะ (✅ แล้วเสร็จ / 🟡 อยู่ระหว่างดำเนินการ / 🔴 ล่าช้า)
   - ตารางตัวชี้วัด: ตัวชี้วัด | หน่วยนับ | เป้าหมาย | ผล | ร้อยละ | บรรลุ/ไม่บรรลุ
   - ผลผลิต (Output) และผลลัพธ์ (Outcome) / ผลกระทบ (Impact) แยกให้ชัด
4. **ผลการใช้จ่ายงบประมาณ** — งบที่ได้รับ | เบิกจ่าย | คงเหลือ | ร้อยละการเบิกจ่าย แยกตามหมวด/กิจกรรม
5. **ปัญหา อุปสรรค และแนวทางแก้ไข** — ตารางคู่ ปัญหา → การแก้ไขที่ทำแล้ว/ที่เสนอ
6. **ข้อเสนอแนะ** และ **แผนงานระยะต่อไป**
7. **ภาคผนวก** — ภาพกิจกรรม (พร้อมคำบรรยาย), รายชื่อผู้เข้าร่วม, เอกสารอ้างอิง

## หลักการเขียน

- ใช้ภาษาทางการ กระชับ เริ่มแต่ละหัวข้อด้วยข้อสรุปก่อนรายละเอียด
- ทุกตัวเลขต้องมาจากข้อมูลที่ผู้ใช้ให้ ถ้าไม่มีข้อมูลให้เขียน "(รอข้อมูล)" ห้ามประมาณหรือแต่งตัวเลข
- ใส่กราฟเมื่อช่วยให้เห็นภาพ: แผน-ผล (แท่งคู่), การเบิกจ่ายสะสมรายเดือน (เส้น), สัดส่วน KPI ที่บรรลุ (แท่งแนวนอน) — หลีกเลี่ยงกราฟวงกลม 3 มิติ
- ฟอนต์ TH Sarabun New 16 pt สำหรับ Word, ตารางมีหัวตารางชัดเจน ตัวเลขชิดขวา ใส่จุลภาคหลักพัน
- ปี พ.ศ. และปีงบประมาณ (1 ต.ค. – 30 ก.ย.) เมื่อเป็นหน่วยงานรัฐ
