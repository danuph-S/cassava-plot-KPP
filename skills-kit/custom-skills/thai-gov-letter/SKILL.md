# หนังสือราชการภาษาไทย

## ขั้นตอน

1. **ระบุชนิดหนังสือ** ถ้าผู้ใช้ไม่บอก ให้เลือกตามผู้รับ:
   - ส่งถึงหน่วยงานอื่น/บุคคลภายนอก → **หนังสือภายนอก** (ใช้ครุฑสูง 3 ซม.)
   - ภายในกระทรวง/กรม/หน่วยงานเดียวกัน → **บันทึกข้อความ (หนังสือภายใน)** (ครุฑสูง 1.5 ซม.)
   - เรื่องไม่สำคัญ ระดับกรมขึ้นไป → หนังสือประทับตรา
   - สั่งการ → คำสั่ง / ระเบียบ / ข้อบังคับ
   - แจ้งให้ทราบทั่วไป → ประกาศ / แถลงการณ์ / ข่าว
2. **ถามเฉพาะข้อมูลที่ขาดจริง** (ถามครั้งเดียวรวมกัน): ส่วนราชการเจ้าของเรื่อง, เลขที่หนังสือ (ถ้ายังไม่มีให้เว้น `ที่ ......../........`), วันที่, ผู้รับ (เรียน ...), อ้างถึง/สิ่งที่ส่งมาด้วย, ชื่อ-ตำแหน่งผู้ลงนาม, เบอร์ติดต่อ. ข้อมูลที่ไม่ทราบให้เว้นจุดไข่ปลาไว้ ห้ามแต่งชื่อคนหรือเลขที่หนังสือขึ้นเอง
3. **เขียนเนื้อความแบบ 3 ย่อหน้า**: เหตุที่มีหนังสือไป (ด้วย/เนื่องจาก/ตามที่...) → วัตถุประสงค์/รายละเอียด (ในการนี้/จึง...) → สรุปความประสงค์ (จึงเรียนมาเพื่อโปรดทราบ/พิจารณา/อนุเคราะห์ ...)
4. **สร้างไฟล์ .docx** ด้วย skill `docx` (ถ้ามี) หรือ python-docx ตามสเปกด้านล่าง แล้วส่งไฟล์ให้ผู้ใช้ พร้อมแสดงเนื้อความในแชตให้ตรวจ

## สเปกการจัดหน้า (แนวปฏิบัติทั่วไปของส่วนราชการ)

| รายการ | ค่า |
|---|---|
| กระดาษ | A4 |
| ฟอนต์ | TH Sarabun New (หรือ TH SarabunPSK) ขนาด 16 pt ทั้งฉบับ, "บันทึกข้อความ" 29 pt ตัวหนา |
| ขอบ | บน 2.5 ซม. (หน้าแรกเริ่มที่ครุฑ 1.5 ซม.), ซ้าย 3 ซม., ขวา 2 ซม., ล่าง 2 ซม. |
| ย่อหน้า | ย่อหน้าแรกของเนื้อความเยื้อง 2.5 ซม. (ประมาณ 10 ตัวอักษร) |
| ระยะบรรทัด | single, ระหว่างย่อหน้า 6 pt |
| การจัดชิด | เนื้อความจัดแบบกระจายแบบไทย (Thai Distributed) |
| ลงชื่อ | เว้น 3–4 บรรทัดสำหรับลายมือชื่อ, (ชื่อเต็ม) ในวงเล็บ, ตำแหน่งบรรทัดถัดไป |

**หนังสือภายนอก** เรียงลำดับ: ที่ (ซ้าย) / ส่วนราชการเจ้าของหนังสือ+ที่อยู่ (ขวา) → วัน เดือน ปี (กึ่งกลางค่อนขวา) → เรื่อง → เรียน → อ้างถึง (ถ้ามี) → สิ่งที่ส่งมาด้วย (ถ้ามี) → เนื้อความ → คำลงท้าย ("ขอแสดงความนับถือ") → ลงชื่อ/ตำแหน่ง → ส่วนราชการเจ้าของเรื่อง + โทร./โทรสาร/อีเมล (มุมซ้ายล่าง)

**บันทึกข้อความ** หัวกระดาษ: ครุฑเล็ก + "บันทึกข้อความ" → ส่วนราชการ ... โทร ... → ที่ ... วันที่ ... → เรื่อง ... → เรียน ... → เนื้อความ → ลงชื่อ (ไม่มีคำลงท้าย)

ครุฑ: ถ้ามีไฟล์ภาพครุฑในเครื่องผู้ใช้ให้ใส่ ถ้าไม่มีให้เว้นพื้นที่และแจ้งให้ผู้ใช้แทรกเอง ห้ามวาดครุฑขึ้นเอง

## ภาษาและคำขึ้นต้น-ลงท้าย

- ใช้ภาษาราชการ สุภาพ กระชับ ไม่ใช้ภาษาพูด, ตัวเลขใช้เลขไทยหรืออารบิกให้สม่ำเสมอทั้งฉบับ (ถามผู้ใช้ถ้าหน่วยงานกำหนด)
- ปี พ.ศ. เสมอ, วันที่รูปแบบ `๑๔ ตุลาคม ๒๕๖๙`
- บุคคลทั่วไป/หัวหน้าส่วนราชการ: "เรียน ... / ขอแสดงความนับถือ"
- องคมนตรี, ประธานองคมนตรี, นายกรัฐมนตรี, ประธานรัฐสภา ฯลฯ: "กราบเรียน ... / ขอแสดงความนับถืออย่างยิ่ง"
- พระภิกษุ: ใช้คำตามสมณศักดิ์ (เช่น "นมัสการ ... / ขอนมัสการด้วยความเคารพ")
- ลงท้ายเนื้อความตามเจตนา: "จึงเรียนมาเพื่อโปรดทราบ" / "...โปรดพิจารณา" / "...โปรดพิจารณาอนุเคราะห์" / "...โปรดพิจารณาอนุมัติ"

## ข้อควรระวัง

- รูปแบบอาจต่างกันเล็กน้อยตามหน่วยงาน ถ้าผู้ใช้แนบแบบฟอร์มของหน่วยงานมา ให้ยึดแบบฟอร์มนั้นก่อนสเปกนี้
- ห้ามสร้างเลขที่หนังสือ ชื่อผู้ลงนาม หรือข้อมูลอ้างอิงที่ผู้ใช้ไม่ได้ให้
- ตรวจคำราชาศัพท์และชื่อตำแหน่งให้ถูกต้อง ถ้าไม่แน่ใจให้ทำเครื่องหมายแจ้งผู้ใช้
