# อินโฟกราฟิกภาษาไทย

## ขั้นตอน

1. **สรุปเนื้อหา** ให้เหลือหัวข้อหลัก 1 ข้อ + ประเด็นย่อย 3–7 ข้อ + ตัวเลขเด่น 1–3 ตัว. ตัวเลขต้องมาจากข้อมูลของผู้ใช้เท่านั้น
2. **เลือกขนาด** ตามปลายทาง:
   | ปลายทาง | ขนาด (px) |
   |---|---|
   | Facebook/IG โพสต์ | 1080 × 1350 |
   | IG/TikTok Story | 1080 × 1920 |
   | สไลด์/จอ | 1920 × 1080 |
   | โปสเตอร์ A4 แนวตั้ง | 2480 × 3508 |
3. **เลือกเลย์เอาต์**: รายการลำดับ (Top N), ขั้นตอน (Process), เปรียบเทียบ (A vs B), ไทม์ไลน์, ตัวเลขสถิติ (Big numbers), แผนผัง/วงจร
4. **เขียน HTML ไฟล์เดียว** ที่กำหนด `width`/`height` ของ `body` ตรงกับขนาดภาพ:
   - ฟอนต์ไทยจาก Google Fonts: `Noto Sans Thai`, `Prompt`, `Kanit`, `Sarabun` (หัวข้อใช้ Prompt/Kanit ตัวหนา, เนื้อความใช้ Sarabun/Noto Sans Thai)
   - ตั้ง `line-height` อย่างน้อย 1.5 สำหรับภาษาไทย (สระบน-ล่างจะไม่ชนกัน)
   - สีหลักไม่เกิน 3 สี + สีพื้น, คอนทราสต์ข้อความ ≥ 4.5:1
   - ไอคอนใช้ SVG แบบ inline หรือ emoji ห้ามดึงภาพจากเว็บที่ไม่ทราบลิขสิทธิ์
   - ถ้าผู้ใช้มีโลโก้/สีองค์กร ให้ใช้ของผู้ใช้
5. **แปลงเป็น PNG** ด้วยสคริปต์ที่มากับสกิล:
   ```bash
   python scripts/render.py infographic.html infographic.png --width 1080 --height 1350
   ```
   (ต้องมี `pip install playwright` และ `playwright install chromium` ครั้งแรก)
6. **ตรวจภาพที่ได้** ด้วยการเปิดดูไฟล์ PNG: ตัวหนังสือล้นกรอบไหม, สระลอย/ซ้อนไหม, ตัดคำผิดที่ไหม — แก้แล้ว render ใหม่จนเรียบร้อย ก่อนส่งให้ผู้ใช้

## ข้อควรระวัง

- ภาษาไทยไม่มีเว้นวรรคระหว่างคำ: หัวข้อยาวให้ขึ้นบรรทัดเองด้วย `<br>` ตรงจุดที่อ่านเป็นธรรมชาติ
- ห้ามแต่งตัวเลข สถิติ หรือแหล่งอ้างอิงขึ้นเอง ถ้ามีแหล่งข้อมูลให้ใส่ "ที่มา: ..." มุมล่าง
