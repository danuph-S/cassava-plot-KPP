# วางแผนวิเคราะห์ข้อมูล

## ขั้นที่ 1 — ทำความเข้าใจโจทย์ (ห้ามข้าม)

ถามครั้งเดียวรวมกันเฉพาะที่ยังไม่ชัด:
- อยากรู้อะไร / จะเอาผลไปตัดสินใจเรื่องอะไร
- ข้อมูลมาจากไหน เก็บอย่างไร (ทดลองแบบสุ่ม, สำรวจ, บันทึกการผลิต, แบบสอบถาม)
- ผู้อ่านผลคือใคร (ผู้บริหาร, นักวิจัย, เกษตรกร) และต้องการไฟล์แบบไหน

## ขั้นที่ 2 — สำรวจข้อมูล

อ่านไฟล์ด้วย pandas แล้วรายงาน: จำนวนแถว/คอลัมน์, ชนิดตัวแปร, ค่าว่าง, ค่าผิดปกติ (outlier), ค่าซ้ำ, หน่วยไม่สอดคล้อง. อย่าแก้ข้อมูลเงียบๆ — แจ้งผู้ใช้ทุกครั้งที่ตัดหรือแทนค่า

## ขั้นที่ 3 — เขียนแผนให้ผู้ใช้อนุมัติ

ตารางแผน: คำถาม | ตัวแปรตาม | ตัวแปรต้น/ปัจจัย | วิธีวิเคราะห์ | สมมติฐานที่ต้องตรวจ | ผลลัพธ์ที่จะได้ (ตาราง/กราฟ)

แนวเลือกวิธี:
| สถานการณ์ | วิธี |
|---|---|
| เปรียบเทียบค่าเฉลี่ย 2 กลุ่ม | t-test (ไม่ปกติ → Mann-Whitney) |
| เปรียบเทียบ ≥3 กลุ่ม / หลายกรรมวิธี | ANOVA + post-hoc (Tukey/LSD/DMRT); ไม่ปกติ → Kruskal-Wallis |
| แปลงทดลอง RCBD / CRD / Factorial / Split-plot | ANOVA ตามแผนการทดลอง (ระบุ block/ซ้ำ), รายงาน CV% |
| ความสัมพันธ์ตัวแปรต่อเนื่อง | Correlation, Regression (เชิงเส้น/พหุ) |
| ตัวแปรกลุ่ม × ตัวแปรกลุ่ม | Chi-square |
| แนวโน้มตามเวลา | กราฟเส้น, ค่าเฉลี่ยเคลื่อนที่, decomposition ตามฤดูกาล |
| แบบสอบถาม Likert | ค่าเฉลี่ย ± SD พร้อมเกณฑ์แปลผล, Cronbach's alpha |

## ขั้นที่ 4 — วิเคราะห์และตรวจสมมติฐาน

ใช้ Python (pandas, scipy, statsmodels) ตรวจ normality / homogeneity of variance ก่อนเลือกการทดสอบ เก็บโค้ดไว้ให้ผู้ใช้รันซ้ำได้

## ขั้นที่ 5 — สรุปผล

- เริ่มด้วยคำตอบของคำถามเป็นภาษาธรรมดา แล้วจึงตามด้วยค่าสถิติ (เช่น F, p-value, ค่าเฉลี่ย ± SE)
- แยก "มีนัยสำคัญทางสถิติ" ออกจาก "มีความสำคัญในทางปฏิบัติ"
- ระบุข้อจำกัดของข้อมูลเสมอ
- ส่งออกเป็นรายงาน (skill `docx`), ตาราง (skill `xlsx`) หรือแดชบอร์ด HTML ตามที่ผู้ใช้ต้องการ
